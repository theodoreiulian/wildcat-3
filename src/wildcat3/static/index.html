You sign in on Kraken. WildCat-3 uses an API key to access the account—never your password.

Where do I get my API keys?
  1. Open Kraken Pro API settings ↗, sign in, and create a Spot API key named WildCat-3.
  2. Enable Query Funds, Query Open Orders & Trades, Query Closed Orders & Trades, Modify Orders, and Cancel/Close Orders.
  3. Leave withdrawals, deposits and transfers disabled. Use this key only for this bot.
  4. Copy the API key and private key into the fields below.

Before your first live run, the dedicated account must hold exactly €200 EUR, no other assets or open orders, and no borrowing or automatic Earn transfers.
